# Rule: Review

- Author ≠ reviewer. Whoever produced an artifact never reviews or signs it off.
- Prefer a different model for the reviewer than the author (kills author bias).
- Review is adversarial: try to break the work. An adversarial verifier defaults to
  "refuted / not ready" when uncertain, not "looks fine."
- Dedup findings across reviewers before acting; fix CRITICAL/HIGH before the next gate.
- Reviews produce evidence (what was run, what was seen), not opinions.
