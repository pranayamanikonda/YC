How it works

The converter renders your HTML in a real browser engine at the exact screen size you choose, reads every computed style and box, and rebuilds the page the way a designer would in Figma.

Render at your screen size

The page is laid out in an isolated iframe at e.g. 393 × 852 or 1440 × 1024, so media queries, vh units and web fonts resolve exactly like on that device.

Infer auto layout

Flexbox maps directly (direction, gap, justify, align, wrap, grow). Block flow and grids are analysed geometrically — stacked children become vertical auto layout, rows become horizontal, tiles become wrap. Margins fold into padding and gap. Irregular spacing is regrouped so each stack has one consistent gap.

Decide sizing

Children spanning their parent become Fill container, content-sized boxes become Hug contents, everything else stays Fixed. Centred max-width containers become Fill + max width. Text gets the right auto-resize mode.

Snap to the grid

Padding, gaps, radius, fixed sizes and positions are snapped to your 4pt or 8pt grid; font sizes to a type scale; line heights to 4pt. The report lists every value that moved.

Build the system

Repeated structures become components (similar ones become variants with TEXT properties), colours become variables, typography becomes text styles, spacing and radius become number variables — all bound to the layers.

Design rules, enforced

On an 8pt grid every spacing value is a multiple of 8, with 4 allowed as a half-step below 16 for tight UI (icon gaps, chips). On a 4pt grid everything is a multiple of 4. Radii follow the same steps; pills stay pills.

The Figma plugin

The plugin runs the same engine inside Figma and builds the layers directly. Use it on its own, or export from this site and import the .h2f.json.

1

Install (development)

Download the html-to-figma/plugin folder. In the Figma desktop app: Plugins → Development → Import plugin from manifest… and pick plugin/manifest.json.

2

Convert

Run HTML to Figma. Paste or drop HTML, a screenshot, or a JSON export from this site. Pick the screen size and grid, then press Convert.

3

Get a real file

You get a screen frame with auto layout, a Components section with variants, a Tokens variable collection and text styles — reused across imports.

Screenshot → editable layers

Images are rebuilt by Claude into grid-aligned flexbox HTML (with repeated items written as identical markup), then flow through the same converter. Your API key stays on your device. Prefer tracing? Place the image as a reference frame instead.

Privacy

HTML is rendered locally — in your browser or the plugin's iframe. Nothing is uploaded, except the image you explicitly send to the Anthropic API for AI rebuilding.

FAQ & limits

Can it import a live URL?

Browsers block reading other sites' HTML (CORS). Save the page (⌘S → "Webpage, Complete") or copy its HTML from DevTools and drop it here; set a Base URL so relative images and CSS resolve.

Fonts

Fonts are matched by family and weight against what's available in Figma (Google Fonts are built in). Generic stacks like system-ui fall back to Inter.

What isn't converted?

::before/::after content, CSS transforms (kept as their bounding box), animations, hover states, and complex grid-template-areas (imported as wrap or absolute).

Why do some gaps change?

Figma stacks have a single gap. When CSS margins differ between siblings, tightly-spaced runs are grouped (e.g. "Heading group") and the remaining gaps are normalised to the most common grid value. See the Grid report.
