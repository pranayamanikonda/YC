How it works

Rebuilt the way a designer would build it

Your HTML is rendered in a real browser engine at the exact screen size you pick. Then every box is read and rebuilt as Figma structure.

Render

Laid out at 393 × 852 or 1440 × 1024, so media queries, vh units and web fonts resolve like on the device.

Infer auto layout

Flexbox maps directly. Stacked blocks, rows and grids are read from geometry. Margins fold into padding and gap.

Decide sizing

Spanning children Fill, shrink-wrapped boxes Hug, explicit sizes stay Fixed. Centred max-width containers become Fill with a max width.

Snap to the grid

Padding, gaps and radius snap to 4 or 8 pt, sizes to 4 pt, type to a scale, line heights to 4 pt.

Build the system

Repeats become components and variants. Colours, spacing and type become variables and text styles, bound to the layers.

Figma plugin

Build straight into your file

The plugin runs the same engine inside Figma. Convert there directly, or paste what you copied here.

Install

  1. Get the html-to-figma/plugin folder from the repository.
  2. In the Figma desktop app open Plugins → Development → Import plugin from manifest…
  3. Pick plugin/manifest.json and run HTML to Figma.
cd html-to-figma && npm run serve

What lands in your file

  1. A screen frame with auto layout all the way down.
  2. A Components section with variant sets and text properties like Label and Title.
  3. A Tokens collection with color/*, space/* and radius/*, plus text styles. Reused on every import.
FAQ

Good to know

Can it import a live URL?

Browsers block reading other sites' HTML. Save the page, or copy its HTML from DevTools, and set a Base URL under Advanced so relative images and CSS resolve.

Why did some gaps change?

A Figma stack has one gap. When CSS margins differ between siblings, tightly spaced runs are grouped (for example a Heading group), and the remaining gaps snap to the most common grid value. The Grid report lists every value that moved.

How are fonts matched?

By family and weight against what Figma has available, including all Google Fonts. Generic stacks like system-ui fall back to Inter.

What isn't converted?

CSS transforms (the bounding box is kept), animations, hover states, icon-font pseudo-elements and grid-template-areas, which come in as wrap or absolute layout.

Where does my HTML go?

Nowhere. It renders in your browser or in the plugin. Only an image you choose to rebuild with AI is sent, to the Anthropic API, with your own key.
